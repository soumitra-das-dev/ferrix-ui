# `create-ferrix-app`

The official project initializer for [Ferrix UI](https://github.com/soumitra-das-dev/ferrix-ui).

## Quick Start

```bash
# Scaffold with default counter template
npx create-ferrix-app my-app

# Scaffold with bottom tabs navigation
npx create-ferrix-app my-app --template tabs

# Scaffold with file-based router and SQLite
npx create-ferrix-app my-app --router --sqlite
```

## Options

- `--template <blank|hello-counter|tabs|stack|api-client|kitchen-sink>`
- `--router`
- `--navigation`
- `--storage`
- `--sqlite`
- `--tailwind`
- `--i18n`
