# Plan: Milestone 04 — Compiler

## 1. Goal
Build the ahead-of-time (AOT) compiler for `.fsx` files in `crates/ferrix-compiler` and the `ferrix` CLI in `crates/ferrix-cli`.
The compiler translates declarative `.fsx` files into native Rust code implementing components and hooks without any JavaScript engine or reflection.

**Milestone 4 Gate**: `examples/counter/component.fsx` runs end-to-end on Android:
- Ahead-of-time compiled from `.fsx` to Rust.
- Executed in Android runtime / live emulator.
- Asserts:
  1. Exactly 1 JNI call per button click.
  2. Exactly 1 `SetText` patch emitted.
  3. Existing `TextView` instance reused (verified by stable NodeId and Android View reference).

## 3. Detailed Approach & Architecture

### 3.1 Lexer (`lexer.rs`)
- Tokenizes:
  - Keywords: `import`, `from`, `type`, `export`, `function`, `return`, `const`, `let`, `useState`, `useSignal`, `useMemo`, `useEffect`, `useRef`.
  - Punctuation: `{`, `}`, `(`, `)`, `<`, `>`, `</`, `/>`, `:`, `;`, `,`, `=`, `=>`, `.`.
  - Identifiers, StringLiterals, IntegerLiterals, FloatLiterals.
  - Spans: track `line`, `col`, `start_offset`, `end_offset` for precise error reporting.

### 3.2 Parser (`parser.rs`)
- Parses:
  - Top-level: `ImportDecl`, `TypeDecl`, `ComponentDecl`.
  - Inside Component:
    - Statements: `const count = useState(props.initial);`
    - Return statement: JSX element tree.
  - JSX Elements:
    - Opening tags: `<ElementName attr={expr} attr="literal">`
    - Children: nested elements, text content, or interpolated `{expr}` expressions.
    - Closing tags: `</ElementName>` or self-closing `/>`.

### 3.3 Semantic Analysis & Diagnostics (`semantic.rs`)
- Hook rules:
  - Must be top-level in component block.
  - Assign hook index slot `0, 1, ...`.
- Emits formatted diagnostics:
  ```
  error[FSX0001]: hooks cannot be called inside conditional blocks
   --> component.fsx:6:9
    |
  6 |     const count = useState(props.initial);
    |     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ hook called conditionally
  ```

### 3.4 Rust Codegen (`codegen.rs`)
- Generates:
  - Props struct:
    ```rust
    #[derive(Clone, Debug, PartialEq)]
    pub struct CounterProps {
        pub initial: i32,
    }
    ```
  - Component function:
    ```rust
    pub fn Counter(cx: &mut ComponentContext, props: CounterProps) -> Element {
        let count = cx.use_state(props.initial);
        Column::new()
            .padding(20.0)
            .spacing(12.0)
            .child(Text::new("Ferrix Counter").size(24.0))
            .child(Text::new(format!("Count: {}", count.get())))
            .child(Button::new("Increment"))
            .build_with_id(NodeId::new(1), cx.allocator())
    }
    ```
