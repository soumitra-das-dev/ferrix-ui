# Plan: F8 Errors, Logging, DevTools & Background Services

## 1. Overview
Under **Architecture A**, Rust runtime logic, error recovery, reactive state inspection, and scheduling are owned by Rust. Kotlin handles Android lifecycle, native frame timing, and platform WorkManager execution.

## 2. Requirements & Slices
1. **Spec**: `docs/devtools.md` detailing error boundaries, router error screen escalation, dev overlay, and WorkManager background jobs.
2. **ErrorBoundary in `ferrix-core`**:
   - `catch_unwind` harness around component subtrees.
   - Fallback UI renderer receiving `ErrorInfo`.
3. **Route `+error.fsx` in `ferrix-router`**:
   - Manifest resolution for nearest ancestor `+error` screen.
   - `router.trigger_error(err)` method updating reactive route state.
4. **`crates/ferrix-devtools`**:
   - `FpsMonitor`: frame duration tracking and FPS calculation.
   - `PatchInspector`: JNI buffer metrics and patch inspection.
   - `SignalInspector`: reactive signal graph debugging.
   - `DevToolsOverlay`: declarative in-app UI element displaying stats.
   - `BackgroundScheduler`: background job registration and tracking.
5. **Android Background WorkManager**:
   - Kotlin adapter for background task scheduling.
6. **Verification**:
   - Unit tests across `ferrix-core`, `ferrix-router`, and `ferrix-devtools`.
   - Android Robolectric unit test.
   - `cargo fmt --check`, `cargo clippy --workspace -- -D warnings`, `cargo test --workspace`, `./gradlew testDebugUnitTest`.
