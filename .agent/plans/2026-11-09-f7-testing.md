# Plan: F7 Headless Component Testing Framework (`ferrix-test`)

## 1. Overview
Under **Architecture A**, UI logic, state updates, reconciliation, and layout are computed in Rust. `crates/ferrix-test` provides a 100% headless test renderer and test harness running on the host machine (no Android emulator, JVM, or device required).

## 2. Requirements & Capabilities
1. **Spec**: `docs/testing.md` outlining the headless testing model, queries, event simulations, timers, and snapshot assertions.
2. **Crate**: `crates/ferrix-test` (in workspace `Cargo.toml`).
3. **Core APIs**:
   - `render(component_fn) -> TestRenderer`:
     - Executes initial render, records `mount_patches`.
     - Automatically diffs on re-render when state changes or events fire.
   - **Queries**:
     - `get_by_text`, `query_by_text`, `find_all_by_text`
     - `get_by_test_id`, `query_by_test_id`
     - `get_by_role`, `find_all_by_role`
     - `get_by_label`, `query_by_label`
   - **Node Operations & Assertions (`TestNode`)**:
     - `node_id()`, `view_type()`, `text()`, `is_visible()`
     - `accessibility_label()`, `accessibility_role()`, `test_id()`
     - `press()`, `change_text()`, `scroll()`, `toggle()`
   - **Synthetic Event Engine (`fire_event`)**:
     - `fire_event::press(&mut renderer, node_id)`
     - `fire_event::change_text(&mut renderer, node_id, text)`
     - `fire_event::value_change(&mut renderer, node_id, value)`
     - Dispatches registered event handlers, re-renders, and tracks patches.
   - **Mock Timer & Scheduler (`FakeTimers`)**:
     - `advance_timers_by_time(ms: u64)`
     - `run_all_timers()`
     - Deterministic time advancement for debounce, throttle, delays.
   - **Snapshot & Diagnostics**:
     - `to_snapshot(&self) -> String`: formatted XML/JSX-like tree representation.
     - Patch count & type assertions (`assert_single_patch`, `patch_history`).
4. **Tests & Verification**:
   - `crates/ferrix-test/tests/test_framework_tests.rs`:
     - Test initial mount queries (`get_by_text`, `get_by_test_id`, `get_by_role`).
     - Test event simulation (`press` increments counter, updates text).
     - Test patch counter (exactly 1 patch on increment).
     - Test fake timers advancing time.
     - Test snapshot output formatting.
5. **Example & Documentation**:
   - `examples/testing/counter_test.rs`
   - `.agent/learnings/testing.md`
   - Update `docs/feature-status.md`
